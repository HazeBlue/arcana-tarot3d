如何占卜

  1. 写下问题　在右侧输入框写下你想问的事，问题越具体，解读越贴合。
  2. 浏览牌阵　78 张牌铺成首尾相接的一圈，可以无限滑动、永远不会到头。正对镜头的那张会浮起并泛光。
  3. 选中三张　依次点击三张牌，它们会飞到桌面上的「现状 / 转折 / 走向」三个位置并翻开。
  4. 阅读解读　三张牌齐备后自动生成结合你问题的专属解读。

怎么操作

  • 左右拖动 / 滑动　按住画面左右拖（手机上直接用手指滑），牌扇会跟着手平移，松手后带惯性并自动对齐到最近的一张牌
  • 点击 / 轻点某张牌　直接把它抽出来，不用先对齐再确认
  • 把鼠标停在牌上　那张牌会被抬到正中并点亮
  • 上下拖动　抬高或压低镜头；滚轮　推近 / 拉远
  • ← / →　键盘浏览，长按可连续滑动；空格 / 回车　抽出正对镜头的那张牌
