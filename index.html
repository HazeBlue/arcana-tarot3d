如何占卜

  1. 写下问题　在右侧输入框写下你想问的事，问题越具体，解读越贴合。
  2. 浏览牌阵　牌面呈弧形排开，下方的卡会浮起并泛光，那就是当前聚焦的牌。
  3. 确认三张　依次确认三张牌，它们会飞到桌面上的「现状 / 转折 / 走向」三个位置并翻开。
  4. 阅读解读　三张牌齐备后自动生成结合你问题的专属解读。

键鼠操作

  • ← / →　切换聚焦的牌
  • 空格 / 回车　确认当前聚焦的牌
  • 拖动鼠标　轻微转动视角
  • 滚轮　推近 / 拉远镜头

手势操作

  • ✋ 张开手掌左右滑动　快速浏览牌阵，滑动越快跨度越大
  • ✊ 并拢握拳并保持半秒　确认当前聚焦的牌
  • 手掌位置　手掌缓慢移动时会带动镜头轻微视差，增强临场感
