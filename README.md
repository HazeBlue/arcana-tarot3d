# Arcana · 三维塔罗

一个基于 three.js 的沉浸式塔罗牌 Web 应用：实时抽取三张牌、摄像头手势操控、结合问题即时生成专属解读。

全部视觉资源（牌背曼陀罗、78 张牌面、光晕、星空、地面纹样）都由 Canvas 2D 在运行时程序化绘制，仓库内没有任何二进制美术资源，因此体积极小、风格完全统一，也便于自由换肤。

---

## 核心功能

### 1. 实时抽卡与三维展示

- 23 张牌以扇形铺开在「弧形轮播」牌阵上，聚焦的那张会浮起、放大并点亮金色光晕
- 选中后卡牌沿贝塞尔弧线飞向桌面上的「现状 / 转折 / 走向」三个牌位，落位瞬间喷发金色粒子，随后翻面
- 每张牌有约 34% 的概率为逆位，逆位牌会在牌面平面内真实旋转 180 度
- 牌面贴图按需生成：牌背朝上时只占用一张共用贴图，翻开哪张才画哪张

### 2. 摄像头手势交互

| 手势 | 作用 |
| --- | --- |
| 张开手掌左右滑动 | 浏览牌阵；滑动越快，一次跨越的牌越多（1~4 张） |
| 并拢握拳并保持 0.42 秒 | 确认当前聚焦的牌 |
| 手掌缓慢移动 | 带动镜头产生视差，增强临场感 |

手势识别链路：MediaPipe HandLandmarker 输出 21 个关键点，手势识别器把关键点翻译成语义事件（swipe / confirm / posture / move），App 层完全不需要区分事件来自手势还是键鼠。

没有摄像头、拒绝授权或环境不支持 https 时，会自动降级到键鼠操作，功能不缺失：

| 键鼠操作 | 作用 |
| --- | --- |
| ← / → 或 A / D | 切换聚焦的牌 |
| 空格 / 回车 / 单击画布 | 确认当前聚焦的牌 |
| 拖动鼠标 | 转动视角 |
| 滚轮 | 推近 / 拉远镜头 |

### 3. 实时解答

用户写下任意问题后，解读引擎会：

1. 分析问题类别（感情 / 事业 / 财运 / 学业 / 身心 / 人际 / 抉择 / 成长 / 内在 / 综合）
2. 识别提问类型（是非题 / 选择题 / 趋势题 / 开放题）
3. 逐张牌组装解读段落：位置模板 + 元素透镜 + 牌面意象 + 关键词
4. 依据正逆位分布给出综合结论、能量评估、三条行动建议与一条提醒

解读文本使用「问题 + 牌组」哈希作为种子随机数，因此同一问题配同一组牌的结果稳定可复现，而不同问题之间的措辞又不会重复。

### 4. 视觉表现

- 深空黑底 + 香槟金描边 + 玻璃拟态面板
- UnrealBloomPass 泛光通道，只有金色描边与光晕溢出
- 程序化「暗色影棚」环境贴图（黑色房间 + 暖金 / 幽紫 / 暖橙三块发光板），让金属只反射金紫色光斑而不是一片惨白
- ACES 电影级色调映射、指数雾、星空三层视差、星云、空气浮尘、地面光池
- 竖屏自动切�换取景：拉远、抬高、放宽视野，并收窄三个牌位间距

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 即可。

摄像头只在 localhost 或 https 下可用，因此建议通过 `npm run dev` 访问，而不是直接双击 index.html。

打包静态产物：

```bash
npm run build
```

产物在 `dist/`，可直接部署到任意静态托管。

## 一些实现上的取舍

牌面贴图按需生成
牌阵里有 23 张牌，若启动时全部绘制需要约 60MB 显存。因为牌背朝上时只需要一张共用贴图，所以牌面被推迟到翻开前一刻才画，启动显存占用降到可忽略，代价是翻开瞬间会有约 20 毫秒的绘制开销。

手势计时使用推理帧间隔
手部推理上限是 30fps，而渲染循环通常是 60fps。如果把渲染帧的 dt 直接喂给手势识别器，握拳保持时长的判定会被放大一倍。因此 HandTracker 会单独统计「距上一次推理的真实时间」并随帧事件传出。

ExtrudeGeometry 的倒角会改变厚度
开启 bevel 后卡牌的实际 Z 跨度是 `depth + 2 × bevelThickness`，而不是 `depth`。牌面与牌背平面必须贴在真实半厚度之外，否则会被牌体吞掉，表现为「牌背永远显示为一块纯金板」。

透明物体永远最后绘制
星云是半透明加色混合材质，会排在所有不透明物体之后渲染。因此它的 `depthTest` 必须开启，否则会穿透桌面糊在画面前景。
